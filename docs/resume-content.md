### StudyOS | Full-Stack AI Learning Management System
**Python, Django, PostgreSQL, Google Gemini API, Bootstrap 5, Render**
* Designed and developed a full-stack Learning Management System using Django and PostgreSQL, supporting Role-Based Access Control (RBAC) for Teachers and Students.
* Integrated the Google Gemini API using Pydantic schemas to automatically generate structured, multiple-choice quizzes, reducing teacher assessment creation time by over 80%.
* Architected a monolithic MVC application featuring custom authentication, file-upload assignments, and an automated grading service abstracting complex business logic.
* Optimized database performance by resolving N+1 query inefficiencies using Django’s `select_related` and `prefetch_related`, improving dashboard load times significantly.
* Built an interactive Analytics Dashboard utilizing Chart.js to aggregate and visualize class performance trends and individual student strengths/weaknesses.
* Secured and deployed the application to production using Render, configuring WhiteNoise for static file delivery and `django-environ` for environment variable management.
* Implemented comprehensive test coverage for critical workflows (Auth, Enrollment, Assessment) using `django.test.TestCase`, ensuring robust CI/CD stability.
